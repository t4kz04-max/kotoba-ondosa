## 1. 30秒で魅力を伝える体験シナリオ

使用する機能は PRD の必須機能（F1〜F9）のみ。ひとりモードで「すぐ行く」を使う。

| 時間 | 画面 | 操作 | 見ている人に伝わること |
|---|---|---|---|
| 0〜3秒 | スタート | 問い「あなたの『すぐ行く』は、何分後？」を見て「ひとりで体験する」 | 何をするアプリか |
| 3〜5秒 | 選択 | 「すぐ行く」を選ぶ | 日常の場面の話であること |
| 5〜15秒 | 入力 | 「早くて 0分」「遅くて 5分」にして決定 | 自分の感覚を範囲で答える |
| 15〜25秒 | 比較 | 架空サンプル「ソラ」（15分〜30分）と同じ軸に並ぶ。「重なりませんでした」「10分のひらき」 | **同じ言葉なのに、思い浮かべる時間がこんなに違う** |
| 25〜30秒 | 具体化→完了 | 「ほかの時間」で 10分 を選び、「今から10分以内に、本当に着けそう？」にチェックして「今から10分以内に着くね」が完成（ひとりモードの完了画面は「具体的な言い方を考えられた。」。「ことばが、約束になった。」はふたりモードで2人が確認したとき） | 違いを知ったら、実際にできる具体的な言葉にできる |

ポイント：

- 説明文を読ませない。問いかけ・スライダー・図だけで進む。
- 驚きの中心は比較画面。2本の帯が離れて表示される瞬間を必ず見せる。
- 「どちらが正しい」とは言わない。ナレーションでも「ソラは遅い」ではなく「思い浮かべる時間が違う」と言う。

## 2. ひとりで試せるデモシナリオ

1. 「ひとりで体験する」→ 好きな言葉を選ぶ → 自分の範囲を入力。
2. 比較画面で、最初の架空サンプルとの違いを見る。
3. 「ほかのサンプルとくらべる」で残り2人に切り替え、重なり方（重なる／包含／離れる）が変わることを見る。
4. 具体化で時間を選び、「本当にできそう？」を確認して完了。「本当の相手と使うときは、相手にも確認しよう」を読む。

体験のねらい：架空の3人とくらべることで、「自分の感覚も、いろいろある感覚の1つ」だと気づく。ただし3人の平均や多数派は示さない。

## 3. 2人で試せるデモシナリオ

1. 「ふたりで比べる」→ 言葉を選ぶ。
2. A が入力 → 交代画面（A の回答は隠れる）→ 端末を B に渡す。
3. B が入力 → 公開前画面「2人で画面を見てね」→ 2人で「2人でくらべる」。
4. 結果を2人で見て話す（「え、5分だと思ってた」）。
5. 具体化画面の手がかり（A の範囲の終わり／B の範囲の終わり／共通範囲の終わり）を見ながら、2人で時間を決める。手がかりは「感じ方」から出したもので、その時間で本当にできるかは別に話し合う。
6. A・B がそれぞれ「この時間でできる／待てる」にチェックして「OK」→ 完了。

体験のねらい：相手の回答を知らないまま答えるので、結果に本物の驚きが生まれる。最後に2人で決めることで、言い換えが「自分たちの約束」になる。

## 4. 最も印象的な比較結果

**「重ならない（gap）」**が最も驚きが大きい。

- 例（架空）：あなた「すぐ行く」＝ 0分〜5分、ソラ（架空）＝ 15分〜30分
  - 見出し：「2人の『すぐ行く』は重なりませんでした」
  - 説明：「2人の範囲のあいだには 10分 のひらきがあります」「範囲のまんなかは 20分 ちがいます」
- 計算（DOMAIN_SPEC §5）：intersection = null、gap = 900 − 300 = 600秒（10分）、中心値 150秒・1350秒 → 差 1200秒（20分）

次に印象的なのは「包含」：一方が「0分〜30分」と広く、もう一方が「5分〜10分」と狭い場合。「同じ範囲に入っているのに、幅がまったく違う」ことが分かる。

## 5. 予選動画で見せるべき場面

| 順 | 場面 | 目安 |
|---|---|---|
| 1 | 問いかけ（「あなたの『すぐ行く』は何分？」）を画面いっぱいに | 3秒 |
| 2 | スライダーで範囲を入力する手元 | 5秒 |
| 3 | **比較結果：2本の帯が離れて並ぶ瞬間**（最重要） | 7〜10秒 |
| 4 | ふたりモード：交代画面で端末を渡す様子（回答が隠れていることを見せる） | 5秒 |
| 5 | 2人で結果を見て反応する様子（出演者の同意を得る） | 5秒 |
| 6 | 具体化：候補を見て時間を選び、「今から10分以内に着くね」ができる | 5秒 |
| 7 | 副題「同じ言葉なのに、同じ意味じゃない。」で締める | 3秒 |

注意：

- 動画内のサンプル・回答例は架空であることをテロップで示す。
- 「調査の結果、◯%の人が…」のような実在データに見える表現を使わない。
- 出演者の顔・名前を映す場合は本人（未成年の場合は保護者）の同意を得る。

## 6. 本選で初見の来場者が操作する場合の注意

- **開始状態**：スタート画面を表示しておく。前の人が途中で離れた場合、スタッフ（または次の人）が「最初から」で戻す（自動リセットは拡張機能 X8）。
- **声かけの一言**：「あなたの『すぐ行く』って何分ですか？ 答えてみてください」。それ以上の説明はしない。
- **ひとりで来た人**：ひとりモードを案内する。架空サンプルであることを口頭でも伝える。
- **2人以上で来た人**：ふたりモードを案内し、A が入力中は B に画面を見ないよう声をかける。
- **端末**：縦向きのタブレットまたはスマートフォン。画面の自動回転・自動ロックはオフにする。
- **通信**：オフラインでも動く（ビルド済みファイルをローカルで配信できる）。会場の回線に依存しない。
- **データ**：回答は保存されないことを、聞かれたら説明できるようにする。
- **想定される質問**：「どっちが正しいの？」→「正解はありません。違いに気づいて、具体的に言うのが大事です」。
