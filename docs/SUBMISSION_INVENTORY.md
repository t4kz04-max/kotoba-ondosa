## 5. 応募前に本人が行うこと

1. `docs/SUBMISSION_TEXT.md` の「作成理由」と「その他」（生成AIの段落）を読み、自分の言葉・実際の作業内容に合わせて直す。
2. `release/kotoba-ondosa-playvideo.mp4` を最後まで再生して確認する（必要なら `docs/PLAY_VIDEO.md` の手順で撮り直す）。
3. スマートフォンで `docs/DEVICE_TEST_GUIDE.md` の確認をする（実機は未確認）。
4. 公開する場合は Vercel で公開し、実際の URL を確認してから記載する。
5. 応募フォームに文章を貼り付け、作品データ（ZIP）・プレイ動画・サムネイルをアップロードする。
