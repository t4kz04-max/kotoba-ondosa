# DEVICE_TEST_GUIDE.md

# 言葉の温度差：スマートフォン実機確認ガイド（5〜10分）

自動テストとパソコン上のエミュレーションでは確認できない点を、実際のスマートフォンで確かめるための手順です。
結果は最後の記録表に書き、`docs/RELEASE_CHECKLIST.md` の NOT_TESTED を更新してください。

---

## 0. 準備（1分）

### A. 公開後に確認する（おすすめ）

Vercel などで公開した **https:// の URL** をスマートフォンのブラウザで開きます。
コピー機能（クリップボード）は https でしか動かないため、コピーの確認はこの方法で行ってください。

### B. 公開前に、家の Wi-Fi で確認する

1. パソコンで次を実行します（PowerShell）。

   ```powershell
   npm run build
   npm run preview -- --host
   ```

2. 表示された `Network: http://192.168.x.x:4173/` の URL を、**同じ Wi-Fi** につないだスマートフォンで開きます。
   - 開けない場合は、Windows のファイアウォールで Node.js の通信を許可してください。
   - この方法は http なので、**コピーは失敗する**のが正しい動作です（「コピーできませんでした。言葉を選んだので…」と表示され、文が選ばれた状態になれば OK）。

確認する端末とブラウザ：iPhone の Safari、Android の Chrome（できれば両方）。

## 1. ひとりモード（3分）

1. 「ひとりで体験する」→「すぐ行く」。
2. **スライダーを指で動かす**：「遅くて」のつまみを指でつかんで左右に動かせるか。値（「5分」など）が大きく表示されるか。
3. 「早くて」の **「0分にする」** を押す → 「0分」と表示されるか（「未選択」との違いが分かるか）。
4. **数値入力**：「遅くて」の分の欄をタップ → 数字のキーボードが出るか。「10」と入れて範囲が「0分〜10分」になるか。
5. **キーボードと固定ボタン**：キーボードが出ている間、入力中の欄が隠れないか。キーボードを閉じたあと、画面下の「これで決定」が押せるか。
6. 比較画面：**図の文字**（「あなた」「ソラ（架空）」「0分〜10分」「10分のひらき」など）が読めるか。帯が伸びる演出が1回だけ流れるか。
7. **画面下の「具体的な言葉にする」**が、上下にスクロールしても押せる位置にあるか。iPhone では画面下のバー（ホームインジケーター）と重なっていないか。
8. 「ソラ（架空）が選んだ範囲の終わり」→ チェック →「この言い方にする」。
9. 完了画面で **「この言葉をコピー」** → メモアプリなどに貼り付けて、画面と同じ文（例「今から30分以内に着くね」）か。

## 2. ふたりモード（3分）

1. 最初から →「ふたりで比べる」→「ちょっと待って」。
2. A が答えて決定 → 交代画面で **A の答えが見えない** か → 「Bさんです。はじめる」。
3. B が答えて決定 →「2人の感覚を公開する」。
4. 具体化：候補を1つ選ぶ → A がチェックして「Aさん OK」→ **ほかの候補を選ぶと確認が消える**か（「確認はリセットされました」）。
5. A・B の両方がチェックして OK → 「ことばが、約束になった。」が出るか。

## 3. 場面を変えて比べる（2分）

1. 最初から →「場面を変えて比べる」。
2. 3つの場面にそれぞれ答える（例：0〜5分、5〜10分、2〜5分）。
3. 結果の図で、①②③の帯と、共通する時間（この例では 5分ちょうどの縦線）が見えるか。
4. 「もう一度試す」で場面①が未選択に戻るか。

## 4. 画面の向き・文字の大きさ（任意・1分）

- 端末の文字サイズを大きくしても、ボタンの文字が切れたり重なったりしないか。
- 横向きにしても操作できるか（このアプリは縦向きを基本としています）。
