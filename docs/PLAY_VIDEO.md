# PLAY_VIDEO.md

# プレイ動画：構成・作り方・撮り直しの手順

## 1. 作成済みの動画

| 項目 | 内容 |
|---|---|
| ファイル | `release/kotoba-ondosa-playvideo.mp4`（Git 管理外） |
| 形式 | MP4（H.264、音声なし）、1280×800、30fps |
| 長さ | 約2分16秒（135.5秒） |
| 容量 | 約12MB（上限 500MB） |
| 中身 | 実際に動いているアプリ（ビルド済みの `dist/`）を Microsoft Edge で操作した画面の録画。上 720px が操作画面、下 80px に場面の説明（字幕） |

### 作り方（事実の記録）

1. ビルドしたアプリを `npm run preview` で配信し、Microsoft Edge（ヘッドレス）で 1280×720 の画面として開く。
2. DevTools Protocol でマウス操作・入力を台本どおりに行い（スライダーのドラッグ、数字の入力、ボタンのクリック）、画面のフレームをそのまま保存した。操作が分かるように、録画中だけ灰色の丸（カーソルの印）を重ねている（アプリの機能ではない）。
3. 保存したフレームを記録した時刻どおりに並べ、ブラウザ標準の WebCodecs で H.264 に変換して MP4 にした（外部の動画ソフト・素材・音楽は使っていない）。

静止画のスライドショーではなく、操作中の画面を連続して記録したものです。字幕は、どの場面かを説明するために書き出し時に加えました。

### 構成

| 時間 | 内容 | 下の字幕 |
|---|---|---|
| 0:00〜0:09 | スタート画面（作品名・副題・問いかけ） | Webアプリ「言葉の温度差」　実際の操作画面です |
| 0:09〜0:41 | ひとりで体験する：「すぐ行く」を選び、「0分にする」とスライダーで 0分〜5分 を入力 → 架空のサンプル「ソラ」との比較（公開演出）→ サンプルを「ヒカリ」に切り替え | ひとりで体験する…／架空のサンプル「ソラ」とくらべます（サンプルは説明用の架空の回答です）／ほかの架空のサンプルに切り替えると… |
| 0:41〜1:10 | ふたりで比べる：「ちょっと待って」で A が 1〜3分、交代画面、B が 2〜5分 → 「2人の感覚を公開する」 | ふたりで比べる…／Aさんの答えはかくして…／2人そろって結果を公開します |
| 1:10〜1:38 | 具体化：「2人に共通する範囲の終わり」（3分）→「今から3分以内にそっちへ行くね」→ A・B がそれぞれ確認 →「ことばが、約束になった。」 | くらべた後は…／AさんとBさんが、同じ文をそれぞれ確認します／2人が確認すると… |
| 1:38〜2:11 | 場面を変えて比べる：3場面に 0〜5分・5〜10分・2〜5分 → 3段の図と「3つすべてに共通する時間：ちょうど5分（1点）」 | 場面を変えて比べる…／3つの範囲と… |
| 2:11〜2:15 | 場面比較の結果画面（上部）で終わり | 言葉の温度差 ― 同じ言葉なのに、同じ意味じゃない。 |

- 使っている回答はすべてその場で入力した例です。ひとりモードの相手は架空のサンプルで、字幕でもそう説明しています。統計や調査結果としては紹介していません。
- 個人情報（名前・メールアドレス・端末の画面など）は映っていません。
- 目安（90〜120秒）より少し長めです。短くしたい場合は §2 の手順で撮り直すか、動画編集ソフトで「ほかのサンプルに切り替える」部分などを切り取ってください。

## 2. Windows で撮り直す場合の手順

### 用意

- `npm run build` → `npm run preview` で http://localhost:4173/ を開く（公開後は公開URLでも可）。
- ブラウザのウィンドウを 1280×720 程度にし、ブックマークバーや他のタブなど、個人の情報が映らない状態にする。
- 通知（メール・チャット）をオフにする（Windows の「集中モード」）。

### 録画の方法（どちらか）

- **Xbox Game Bar**：`Win + G` → 「キャプチャ」→ 録画開始（`Win + Alt + R`）。保存先は「ビデオ\キャプチャ」。形式は MP4。
- **Snipping Tool（Windows 11）**：「録画」を選び、範囲をブラウザに合わせて録画。形式は MP4。

### 台本（約100秒）

1. （0〜8秒）スタート画面を映す。作品名「言葉の温度差」と「同じ言葉なのに、同じ意味じゃない。」が見えるようにする。
2. （8〜35秒）「ひとりで体験する」→「すぐ行く」→「0分にする」→「遅くて」のスライダーを 5分 に → 「これで決定」。帯が順に現れるのを待つ。「架空の回答です」の注記が映るようにする。
3. （35〜60秒）右上「最初から」→「ふたりで比べる」→「ちょっと待って」。A：早くて1分・遅くて3分 →「これで決定」→ 交代画面 →「Bさんです。はじめる」→ B：2分・5分 →「これで決定」→「2人の感覚を公開する」。
4. （60〜80秒）「具体的な言葉にする」→「2人に共通する範囲の終わり」→ A のチェック →「Aさん OK」→ B のチェック →「Bさん OK」→「ことばが、約束になった。」を映す。
5. （80〜100秒）「最初から」→「場面を変えて比べる」→ 3つの場面に 0〜5分、5〜10分、2〜5分 → 結果の図と「わかったこと」を映す。

### 注意

- 音楽を入れる場合は、自分で作ったもの、または利用条件で応募・公開が認められている素材だけを使う。
- 500MB 以内であることを確認する（1分あたり数十MB程度が目安）。
