## 2. 作品説明（必須）

<!-- ここから -->
「すぐ行く」「ちょっと待って」「あとでやる」。ふだん何気なく使う言葉でも、思いうかべる時間は人によって違うことがあります。「言葉の温度差」は、その違いを目に見える形にして、相手にきちんと伝わる具体的な言葉に言いかえるまでを体験できるWebアプリです。

使う人は、言葉が当てはまると思う時間を「早くて◯分〜遅くて◯分」という範囲で答えます。答えた範囲は、時間の長さに比例した1本の時間軸の上に並べて表示され、2人の範囲がどこで重なり、どこでずれているか（共通する時間、あいだの空白、範囲のまんなかの差）が一目で分かります。

体験は3つあります。

・ひとりで体験する：説明用に作った架空のサンプル（3人分）と自分の答えをくらべます。サンプルは架空であることを画面に常に表示しています。
・ふたりで比べる：1台の端末を交代で使い、相手の答えを見ないまま答えます。2人とも答え終わってから結果を公開します。
・場面を変えて比べる：同じ「すぐ」を、「すぐ行く」「すぐ返信する」「すぐ始める」の3つの場面で答え、同じ人でも場面によって思いうかべる時間が変わるかどうかを調べます。

くらべたあとは、「今から10分以内に着くね」のように、「いつまでに」「何をするか」がはっきりした文に言いかえます。ふたりモードでは、AさんとBさんがそれぞれ同じ文を確認したときだけ「ことばが、約束になった。」と表示します。

このアプリは、どちらの感じ方が正しいかを判定しません。点数や割合も出しません。回答は保存も送信もせず、ブラウザの中だけで扱います。

## 3. 操作方法（必須）

<!-- ここから -->
パソコン・タブレット・スマートフォンのブラウザで動きます。スマートフォンは縦向きがおすすめです。

【はじめに】
スタート画面で「ひとりで体験する」「ふたりで比べる」「場面を変えて比べる」のどれかを選びます。どの画面でも、右上の「最初から」でスタート画面に戻れます。

【ひとりで体験する】
1. 「すぐ行く」「ちょっと待って」「あとでやる」から言葉を1つ選びます。
2. 場面の説明を読み、「早くて」と「遅くて」の時間をスライダーか数字で入力します。0分にしたいときは「0分にする」を押します。
3. 「これで決定」を押すと、架空のサンプルと同じ時間軸に並んだ結果が表示されます。「全体表示」「拡大表示」で見え方を切り替えたり、ほかのサンプルに切り替えたりできます。
4. 「具体的な言葉にする」を押し、手がかりの時間を選ぶか「ほかの時間」で好きな時間を入力します。
5. 「この言葉のとおりに、実際にできる」にチェックして「この言い方にする」を押すと完成です。「この言葉をコピー」で文をコピーできます。

【ふたりで比べる】
1. 言葉を選び、Aさんが時間の範囲を入力して「これで決定」を押します。Aさんの答えはかくされます。
2. 端末をBさんに渡し、「Bさんです。はじめる」を押してBさんが入力します。
3. 2人で画面を見て「2人の感覚を公開する」を押すと、2人の範囲が順番に表示されます。
4. 「具体的な言葉にする」で時間を選び、AさんとBさんがそれぞれチェックして「OK」を押します。時間を変えると確認はやり直しになります。2人とも確認すると完成です。

【場面を変えて比べる】
1. 3つの場面（①すぐ行く ②すぐ返信する ③すぐ始める）に、順番に時間の範囲を入力します。
2. 3つの答えが同じ時間軸に表示され、3つすべてに共通する時間があるか、範囲のまんなかがどれくらい違うかが分かります。
3. 「もう一度試す」で最初から答え直せます。

キーボードだけでも操作できます（Tab で移動、Enter で決定、矢印キーでスライダー）。

## 4. 作成理由（必須）

<!-- ここから -->
「すぐ行くね」と言われて待っていたのに、なかなか来なかったという経験はないでしょうか。言った人はうそをついたわけではなく、その人にとっての「すぐ」と、聞いた人にとっての「すぐ」が違っていただけかもしれません。

こうした言葉は便利ですが、思いうかべる時間の違いはふだん目に見えないので、違いがあること自体に気づきにくいと考えました。そこで、自分の感じ方を時間の範囲として答え、相手の答えと同じ時間軸に並べれば、違いをはっきり見られるのではないかと思い、このアプリを作りました。

また、違いに気づくだけで終わらせず、「今から10分以内に着くね」のように、相手と確認できる具体的な言葉に言いかえるところまでを一つの体験にしたいと考えました。曖昧な言葉が悪いということではなく、大事なときに具体的に言うきっかけになればと思っています。

## 5. 工夫したところ（必須）

<!-- ここから -->
1. 時間の長さを正確に見せる図
時間軸は、時間の長さと画面上の長さが比例するように作りました。短い範囲を見やすくするために実際より太く描くことはせず、代わりに2人の範囲が収まる「拡大表示」を用意しています。長さが0の範囲は点で、1点だけで接している場合は線で表し、ないはずの重なりが見えないようにしました。2人の範囲は、色に加えて「塗りつぶし」と「斜線」の模様でも区別しています。

2. 重なり方を正しく分類する計算
2つの範囲の関係を「ぴったり同じ」「すっぽり入っている」「一部だけ重なる」「1点だけで重なる」「重ならない」に分け、共通する時間、あいだの空白、範囲のまんなかの差を計算しています。計算の部分は画面の部分と分けて作り、境目のケースを含めて自動テストで確かめています（2026年10月時点で265件）。

3. 相手の答えを見ないで答えられる仕組み
ふたりモードでは、Bさんが答えている間、Aさんの答えは画面にも画面読み上げ用の情報にも出ないようにしています。結果は「2人の感覚を公開する」を押したときに、2人の範囲 → 共通部分や空白 → 説明文の順に表示されます。

4. 「感じ方」と「実際にできること」を分けたこと
くらべた範囲はあくまで感じ方なので、そこから出す時間は「手がかり」として示し、選んだ時間で本当にできるかを本人が確認してから決めるようにしました。範囲が重なっていても自動では約束にせず、重なっていなくても話し合えば決められることを伝えています。完成する文は、答えた時間の意味と一致するように「今から◯分以内に着くね」のように、いつからの時間か・何をするかが分かる形にしました。

5. 判定しない・保存しない
どちらが正しいかの判定や、点数・割合は出しません。ひとりモードのサンプルは架空であることを常に表示し、平均や多数派も出しません。回答はブラウザの中だけで扱い、保存も送信もしません。

6. だれでも使いやすく
スマートフォンの縦画面で操作しやすいよう、大事なボタンを画面の下に置き、押せる場所を大きくしました。最初は「未選択」から始まり、0分と未回答を区別しています。入力の間違いは、その入力欄のすぐ下に理由を表示します。キーボードだけでの操作、画面読み上げ用の説明、動きを減らす設定にも対応しています。
